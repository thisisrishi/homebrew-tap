# thisisrishi/homebrew-tap

Homebrew casks for apps by [@thisisrishi](https://github.com/thisisrishi).

```sh
brew install --cask thisisrishi/tap/tangelo
```

| Cask | Description |
|---|---|
| [tangelo](Casks/tangelo.rb) | Convert, edit and move files right where you drag them — [Tangelo](https://github.com/thisisrishi/Tangelo) |
